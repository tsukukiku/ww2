Put aircraft images in this folder with these exact names:

p51d.png
- P-51D player aircraft.
- Source image width should be 512 px.
- The game scales it to the same in-game width as the old P-51D sprite.

me262.png
- Me262 boss aircraft.
- Source image width should be 768 px.
- The game displays it 1.5x wider than the P-51D image.

bf109.png
- Bf109 enemy aircraft.
- The source can be any resolution.
- Use an upward-facing image as the aircraft's forward direction.
- The game displays it about the same width as the P-51D image.

bf110.png
- Bf110 enemy aircraft.
- The source can be any resolution.
- Use an upward-facing image as the aircraft's forward direction.
- The game displays it about 1.5x wider than the P-51D image.

fw190.png
- Fw190 enemy aircraft.
- The source can be any resolution.
- Use an upward-facing image as the aircraft's forward direction.
- The game displays it about 0.8x the width of the P-51D image.

Transparent PNGs are recommended.
